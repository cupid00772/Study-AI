# Output Template Reference

This file contains the exact Markdown template that the Study Material Generator should follow when producing each chapter's study material.

---

## Single Chapter Template

```markdown
# Chapter [X]: [章節標題]

> 📅 生成日期：[YYYY-MM-DD]
> 📄 來源檔案：[原始檔案名稱]

---

## 🗺️ 知識架構總覽 (Tree Diagram)

\```mermaid
mindmap
  root(("Chapter X: 標題"))
    Section 1 名稱
      Concept A
        Sub-concept A1
        Sub-concept A2
      Concept B
    Section 2 名稱
      Concept C
        Sub-concept C1
\```
